**1. T(n) — как растёт число операций при увеличении числа визитов. Какие именно операции учитывались.**
1. Группировка по часам: один проход по списку visits — O(n). Поиск по словарю — O(1), так как идёт сразу по ключу. append — O(1).
2. Сортировка: O(n log n).
3. Проход по breeds — q операций, что меньше n.
Итог: O(n log n) + O(n) = O(n log n) в худшем случае.

**2. S(n) — сколько дополнительной памяти функция занимает сверх входных данных.**
Создаётся новый словарь (структура данных), в который заносятся все породы — O(n) по памяти.

**3. Худший случай: при каком журнале работы нагрузка наибольшая и почему.**
По времени: O(n log n) — при условии, что все часы визитов различны и идут не по порядку, тогда сортировать приходится весь список.
